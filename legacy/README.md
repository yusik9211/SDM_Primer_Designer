| File | Version | Notes |
|------|---------|-------|
| `sdm_primer_designer_v1.html` | v1 | Single mutation only |
| `sdm_primer_designer_v1.py`   | v1 | Single mutation only |
| `sdm_primer_designer_v2.html` | v2 | Multi-mutation support; no gene name field |
| `sdm_primer_designer_v2.py`   | v2 | Multi-mutation support; no gene name field |
| `sdm_primer_designer_v3.html` | v3 | Adds gene naming, primer naming convention, and Site Saturation Mutagenesis (SSM) mode |
| `sdm_primer_designer_v3.py`   | v3 | Adds gene naming, primer naming convention, and Site Saturation Mutagenesis (SSM) mode |

For the latest version, see the [main page](../) and its [Version History](../README.md#version-history).
